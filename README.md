# EcoTransit
## Analysis of Public Transport Usage vs CO₂ Emissions

### Project Overview
This project analyzes the relationship between public transport usage and CO₂ emissions
to understand how transportation choices impact environmental sustainability.

### Dataset Information
- CO₂ emissions data is included in this repository.
- Public transport usage data is very large (>1GB) and therefore not included.

The transport usage dataset can be downloaded from:
https://www.google.com/covid19/mobility/

### Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
